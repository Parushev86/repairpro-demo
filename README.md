# 🔧 RepairPro — Инсталационно ръководство

## Какво е RepairPro?
Десктоп CRM система за сервизи на мобилни устройства.
Работи на Windows, данните се пазят в облака (Supabase) — 
**реален синхрон между 2 компютъра в секунди**.

---

## 📦 СТЪПКА 1 — Инсталирай Node.js

1. Отвори https://nodejs.org
2. Изтегли **LTS версията** (препоръчана)
3. Инсталирай с всички настройки по подразбиране
4. Рестартирай компютъра

---

## 🗄️ СТЪПКА 2 — Настрой базата данни (Supabase)

1. Отвори **https://supabase.com** и създай безплатен акаунт
2. Кликни **"New project"** → избери регион **"Europe (Frankfurt)"**
3. Изчакай проекта да се създаде (~1-2 минути)
4. В лявото меню кликни **"SQL Editor"**
5. Копирай целия код от файла **`sql/schema.sql`**
6. Постави го в SQL Editor и натисни **"Run"**
7. Трябва да видиш: *"Success. No rows returned"*

### Вземи API ключовете:
8. В лявото меню: **Settings → API**
9. Копирай **"Project URL"** (изглежда като: https://xxxxx.supabase.co)
10. Копирай **"anon public"** key
11. Запази ги — ще ги трябват след малко

### Включи Realtime (синхрон в реално време):
12. В лявото меню: **Database → Replication**
13. Включи **orders** и **inventory** таблиците

---

## 💻 СТЪПКА 3 — Инсталирай приложението

Отвори **Command Prompt** (Старт → cmd) и изпълни:

```
cd C:\Users\ИМЕ\Downloads\repairpro
npm install
npm run dev
```

Приложението ще се отвори автоматично!

---

## ⚙️ СТЪПКА 4 — Първоначална настройка

При първото стартиране ще се отвори прозорец "Настройки":

1. **Supabase URL** — постави URL-а от Стъпка 2
2. **Supabase Anon Key** — постави ключа от Стъпка 2
3. Кликни **"Запази настройките"**
4. Приложението ще се свърже и зареди данните

---

## 🖥️ СТЪПКА 5 — Инсталирай на втория компютър

1. Копирай папката `repairpro` на втория компютър
2. Инсталирай Node.js на него също
3. Изпълни `npm install` и `npm run dev`
4. Въведи **СЪЩИЯ** Supabase URL и ключ
5. Готово! Двата компютъра са синхронизирани 🎉

---

## 📧 Настройка на имейл (Gmail)

За автоматичен имейл при "Готово устройство":

1. Отвори Gmail → Account → Security → 2-Step Verification (включи)
2. След това: Security → App passwords → "Mail" → генерирай
3. Копирай 16-цифрения код
4. В RepairPro Настройки:
   - SMTP сървър: `smtp.gmail.com`
   - SMTP порт: `587`
   - Имейл: `твоят@gmail.com`
   - Парола: 16-цифрения код от по-горе

## 🏗️ Компилиране в .exe файл (по желание)

```
npm run build
```
Ще създаде инсталационен .exe файл в папка `dist/`.

---

## 🆘 Проблеми?

- **"npm не е разпознат"** → рестартирай след инсталация на Node.js
- **"Cannot connect"** → провери URL и ключа в Настройки
- **Имейлът не се изпраща** → провери App Password настройката
